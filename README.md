# US-Arrests-EDA
Exploratory Data Analysis on US Arrests dataset (1973)

## Project Overview
Exploratory Data Analysis on the US Arrests dataset (1973) containing arrest statistics for murder, assault, rape, and urban population for all 50 US states.

## Key Questions
- Which states have the highest crime rates?
- How are different crimes correlated?
- What patterns exist in urban population vs crime?

## Key Findings
1. **Murder:** Georgia has the highest murder rate (17.4 per 100k)
2. **Assault:** North Carolina has the highest assault rate (337 per 100k)
3. **UrbanPop:** California has the highest urban population (91%)
4. **Rape:** Nevada has the highest rape rate (46 per 100k)
5. **Correlations:** Assault and Murder are strongly correlated (0.80)

## Visualizations
- Bar charts for top states
- Histograms showing distributions
- Correlation heatmap
- Scatter plots
